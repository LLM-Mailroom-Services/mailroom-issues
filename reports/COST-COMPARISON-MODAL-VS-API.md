# Cost comparison — Modal L4 (vLLM) vs hosted API

_Data 16–28 Sep 2026 · generated by sandbox `reports/dashboard/export_hub_reports.py` from the cross-checked reports hub · sources: local-mailroom-sandbox @ 5783b472b6e4 · eval-environment @ f6bb5107e138 · mailroom-ml @ d3ad22263da0_

**Bottom line.**

- Per document, the self-hosted Qwen3-8B-AWQ specialists on Modal L4 are cheaper than every hosted model for correspondence and corporate records.
- They cost more than the cheapest hosted model for insurance claims, contracts and merger agreements.
- Quality is the stronger argument against Modal today: a hosted model scores higher on 3 of the 4 tasks scored alike.
- The sorter is decided on cost: ModernBERT matches the best hosted LLM sorter's document-type accuracy at about three orders of magnitude lower cost per document.

## 3. When does Modal pay off? (batch economics)

For a batch of *N* documents on a cold-started 2×L4 fleet, Modal costs `boot + N × modal $/doc` and the API costs `N × API $/doc`. Modal wins once `N > boot / (API $/doc − modal $/doc)`, and only if its per-document cost is lower in the first place. A fleet kept warm costs $1.60/h whether or not it is busy. It beats the cheapest API only while the sustained load stays above the rate in the last column, and it cannot serve more than its measured throughput (the docs/h column).

| Class | Modal $/doc | Cheapest API $/doc | Qwen3.7-Flash $/doc | Modal docs/h (2×L4) | Break-even N vs Qwen3.7-Flash | Break-even N vs cheapest | Warm-fleet break-even docs/h |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| Correspondence | $0.00014 | Qwen3.7-Flash $0.00045 | $0.00045 | 11,233 | 312 | 312 | 3,561 |
| Insurance claims | $0.00054 | Qwen3.7-Flash $0.00051 | $0.00051 | 2,966 | never (API cheaper per doc) | never (API cheaper per doc) | 3,161 |
| Corporate records | $0.00050 | Qwen3.7-Flash $0.00079 | $0.00079 | 3,198 | 336 | 336 | 2,037 |
| Contracts | $0.0022 | Qwen3.7-Flash $0.0015 | $0.0015 | 722 | never (API cheaper per doc) | never (API cheaper per doc) | 1,082 |
| Merger agreements | $0.0043 | Qwen3.7-Flash · frozen $0.0029 | $0.0032 | 374 | never (API cheaper per doc) | never (API cheaper per doc) | 556 |

![Break-even batch size](figures/cost/break-even.svg)

**Reading.**

- Correspondence and corporate records are the only classes where the Modal fleet is cheaper per document than the production API model. A cold-started batch recovers the $0.096 boot after 312 documents (correspondence) and 336 documents (corporate records).
- For insurance claims, contracts and merger agreements, the hosted Qwen3.7-Flash is cheaper per document at every volume. The fleet runs these classes at 2,966, 722 and 374 docs/h, against 11,233 for correspondence.
- Where Modal is cheaper per document, a warm fleet also beats the cheapest API once the sustained load passes 3,561 docs/h for correspondence (32% of measured throughput) and 2,037 docs/h for corporate records (64% of measured throughput). Below that, idle GPU time makes a warm fleet dearer than the API.

## 6. Caveats

- **Draws differ.** Modal: 50 documents per class on revision `ed7576b6` (split all). API: 20 per class (Qwen3.7-Flash 50) on `46a4d3c2`, train split. The per-class means are comparable in scale, not paired.
- **Prompts differ.** The Qwen3.7-Flash legs ran eval-environment's mutated lineage. The other API legs and the Modal runs ran the frozen production prompts, and the Modal merger run used the MAUD prompt.
- **Contracts are not like-for-like.** The Modal point is per-document CUAD category-presence F1. The pipeline rubric returns no score on label-native CUAD ground truth, so the API points use that rubric instead.
- **Busy-window Modal cost is a floor.** The MAUD merger run's summary row, which includes its 122.8 s boot, is 28% higher than its run report. This is documented as a hub data-quality issue.
- **eval-environment files one merger leg under Qwen3-8B**, but the logged model is `qwen/qwen3.7-flash` with the frozen prompts. These reports label it by the logged model ('API · Qwen3.7-Flash (frozen prompts)'), so there is no Qwen3-8B merger point.
